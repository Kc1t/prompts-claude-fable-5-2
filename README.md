# Prompts do Claude Fable 5.2

Os prompts e os sites do vídeo **"Dei Uma Imagem pro Claude Fable 5.2 e Ele Fez Uma Landing Page Inteira"** do canal [Kauã Miguel - Dev](https://youtube.com/@kc_1t).

Tudo foi feito num chat só do Claude, com o Fable 5.2 escrevendo o código e o [Higgsfield MCP](https://higgsfield.ai/mcp) gerando as imagens, os vídeos e os modelos 3D.

## O que tem aqui

| Arquivo | O que é | Site no ar |
|---|---|---|
| [`prompts/teste-1-clonar-site.md`](prompts/teste-1-clonar-site.md) | Clonar um site inteiro com um prompt, adaptando pra sua marca | [kori-app.higgsfield.app](https://kori-app.higgsfield.app) |
| [`prompts/teste-2-imagem-para-landing-page.md`](prompts/teste-2-imagem-para-landing-page.md) | Transformar uma única imagem numa landing page com 3D, animação e efeito no mouse | [evolution-sapientia.higgsfield.app](https://evolution-sapientia.higgsfield.app) |

O código de cada site está no ar: abra o link e veja o código-fonte pelo navegador.

## Como usar

1. Conecte o Higgsfield MCP no Claude: em Configurações, Conectores, adicione um conector personalizado com a URL `https://mcp.higgsfield.ai/mcp`. Conectando pelo link do vídeo você ganha [3 dias grátis](https://higgsfield.ai/s/claude-fable-5-2-yt-kc-1t-idaOwW).
2. Escolha o Claude Fable 5.2. Comece no esforço baixo e só suba pro médio se precisar de mais qualidade: ele gasta bastante.
3. Cole os prompts na ordem, no mesmo chat.

## O que eu aprendi

O Fable 5.2 é melhor planejando e copiando referência do que construindo tudo sozinho. O que funcionou pra mim foi o Fable planejar e o Opus construir.

O teste grátis do Higgsfield MCP pede cartão e vira plano Ultra pago depois dos 3 dias, a não ser que você cancele.
